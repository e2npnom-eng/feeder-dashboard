# แดชบอร์ดเหตุการณ์ฟีดเดอร์ T/R · T/L

หน้าเว็บ static (ไม่ต้องมี server) ขึ้น GitHub Pages ได้เลย

- **สถานี** ดึงจากตัวอักษรหน้ารหัสฟีดเดอร์ เช่น `NNA01R-03` → สถานี `NNA`, `NNB01VR-101` → สถานี `NNB` (เพิ่มสถานี/ฟีดเดอร์ใหม่ได้โดยไม่ต้องแก้โค้ด แค่เพิ่มไฟล์ Excel)
- **T/R** = Trip-Reclose · **T/L** = Trip-Lockout (ตามคอลัมน์ `tripreclose` ในไฟล์)
- วันที่ในไฟล์เป็น พ.ศ. (`dd-mm-yyyy hh:mm`) สคริปต์แปลงเป็น ค.ศ. ภายใน และหน้าเว็บแสดงเป็น พ.ศ.

## โครงสร้าง
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | แดชบอร์ด |
| `data.js` | ข้อมูลที่รวมจาก Excel แล้ว (หน้าเว็บอ่านไฟล์นี้) |
| `data/*.xlsx` | ไฟล์ Excel ต้นทาง — 1 ไฟล์ต่อ 1 ฟีดเดอร์ (`Event_Data_<ฟีดเดอร์>.xlsx`) ใส่ครบทุกฟีดเดอร์ของทุกสถานี |
| `convert.py` | รวมทุกไฟล์ใน `data/` → `data.js` (ตัดแถวซ้ำให้) |
| `.github/workflows/convert.yml` | สร้าง `data.js` อัตโนมัติเมื่อ push ไฟล์ใน `data/` |

## ขึ้น GitHub Pages
push ทุกไฟล์ขึ้น repo → Settings → Pages → Branch `main` / root

## อัพเดทข้อมูล (เลือกวิธีใดก็ได้)
- **A. ผ่านหน้าเว็บ** — กด "⬆ อัพโหลด Excel" หรือลากไฟล์ (เลือกได้หลายไฟล์) มาวาง ข้อมูลใหม่จะถูกรวมเข้าของเดิม (แถวที่ฟีดเดอร์ + เวลา + ประเภทตรงกันจะถูกแทนที่) แสดงผลทันที แต่เก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น → กด "⬇ data.js" แล้ว commit ทับ `data.js` เพื่อให้ทุกคนเห็น
- **B. ผ่าน GitHub** — อัพโหลดไฟล์ใหม่ทับใน `data/` GitHub Actions จะสร้าง `data.js` ให้เอง
- **C. ในเครื่อง** — `pip install openpyxl && python convert.py data data.js`

## รูปแบบ Excel
แถวแรกเป็นหัวคอลัมน์ (รองรับชื่อไทย/อังกฤษ) :

| คอลัมน์ | ชื่อหัวที่รองรับ |
|---|---|
| วันเวลา | `dateoutage`, `date`, `datetime`, `วันที่` |
| ฟีดเดอร์ | `equiptment`, `equipment`, `feeder`, `อุปกรณ์` (ถ้าว่างจะใช้ชื่อจากชื่อไฟล์) |
| ประเภท | `tripreclose`, `type`, `ประเภท` (ค่า `T/R` หรือ `T/L`) |
| รายละเอียด | `reason`, `สาเหตุ` |

แถวที่อ่านวันที่หรือประเภทไม่ได้จะถูกข้าม (แจ้งจำนวนตอนแปลง/อัพโหลด)

## ปรับแต่ง
- **เกณฑ์สถานะ** (ปกติ / เฝ้าระวัง / วิกฤต) ตั้งใน `CFG` บนสุดของ `<script>` ใน `index.html` — ค่าเริ่มต้นเป็นค่าสมมติ นับจากจำนวนเหตุการณ์ 30 วันล่าสุด
- **หมวดสาเหตุ** จัดด้วยคำสำคัญใน `CAUSE` (ต้นไม้, สัตว์, อุปกรณ์ชำรุด ฯลฯ) เพิ่มคำได้ตามต้องการ

## อัพเดทรายวัน
ระบบอ่านได้จากไฟล์ Excel/`data.js` เท่านั้น ไม่ได้อ่านรูปภาพโดยตรง ถ้าต้องการอัพเดทจากรูปแคป ต้องมีขั้นตอนแปลงรูปเป็นแถวข้อมูลก่อน (OCR หรือให้ AI อ่านรูป) แล้วจึงเพิ่มเข้า Excel/`data.js` — ระบบตัดแถวซ้ำให้อัตโนมัติ จึงส่งช่วงวันที่ซ้อนกันได้โดยไม่ซ้ำ
